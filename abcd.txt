// =====================================================================================
//  BSL / SSL LIQUIDITY START SIGNALS — v5 LITE (Webhook & Zero-Delay Parity Edition)
//  ---------------------------------------------------------------------------------
//  Stripped-down build of the NIFTY Liquidity & Bias Engine. EVERYTHING except the
//  buy-side / sell-side liquidity pools was removed: no pivots, no CPR, no S/R zones,
//  no HTF module, no sector breadth, no A/D, no VIX, no dashboard — and therefore
//  ZERO request.security() calls (fast, and works on any symbol/timeframe).
//
//  WHAT IT DOES
//   * Confirmed swing HIGH opens a BUY-SIDE liquidity pool (BSL) above price — the
//     shorts' stop cluster. Equal highs merge into one EQH pool and share a touch
//     count. Confirmed swing LOW opens a SELL-SIDE pool (SSL) below — longs' stops.
//   * Pools live until swept or expired. A sweep = price trades through the level and
//     closes back inside (BSL sweep → bearish marker, SSL sweep → bullish marker).
//     Swept pools stay on chart and get an automatic performance score in R.
//   * START-POINT ENTRY SIGNALS: the moment a FRESH pool is created, its start point
//     is marked with a BUY / SELL label anchored at the actual swing bar.
//     DEFAULT mapping (fade the fresh swing):  new BSL → SELL  ·  new SSL → BUY
//     Alternative "magnet" mapping (via input): new BSL → BUY (drawn up to the pool)
//                                               new SSL → SELL (drawn down to it)
//     TIMING & NON-REPAINTING:
//     A swing can only be mathematically confirmed `pivLen` bars after the actual
//     high/low, so the signal FIRES on the confirmation bar close (non-repainting) while
//     the label is drawn back at the true swing start bar for visual chart clarity.
//
//  MULTI-SPEED TIERS
//   * TIER 3 STANDARD — pivLen=8 confirmation, macro target tracking (original behaviour)
//   * TIER 2 FAST     — fastPivLen=3 (15m on 5m, 3m on 1m) → 62% faster entries
//   * TIER 1 INSTANT  — 0-bar lag on the sweep candle close, wick SL, 1:2 R:R TP
//     Each tier draws its own label and has a dedicated webhook alertcondition.
// =====================================================================================

f_zoneName(bool eq, bool buyside, int id) =>
    (eq ? (buyside ? "EQH" : "EQL") : (buyside ? "BSL" : "SSL")) + "-" + (id < 10 ? "0" : "") + str.tostring(id)

f_zoneText(string nm, int tch, int strn) =>
    lblMode == "Name only" ? nm : nm + " ×" + str.tostring(tch) + " " + f_stars(strn)

// strength 1-5: base 1, +1 equal H/L, +1 two+ touches, +1 four+ touches
f_strength(bool eq, int tch) =>
    v = 1 + (eq ? 1 : 0) + (tch >= 2 ? 1 : 0) + (tch >= 4 ? 1 : 0)
    v > 5 ? 5 : v

f_nearestAbove(array<float> a) =>
    float best = na
    if array.size(a) > 0
        for i = 0 to array.size(a) - 1
            v = array.get(a, i)
            if v > close and (na(best) or v < best)
                best := v
    best
f_nearestBelow(array<float> a) =>
    float best = na
    if array.size(a) > 0
        for i = 0 to array.size(a) - 1
            v = array.get(a, i)
            if v < close and (na(best) or v > best)
                best := v
    best
